# Java Interview Prep

Practice code and notes I wrote while refreshing Java fundamentals for technical interviews.
Each file is a small, runnable example with English comments.

## Contents

### Basics (`src/temeller`)

| File | Topic |
|---|---|
| `Ders1_Baslangic` | Program structure, variables, data types, operators |
| `Ders2_Kosullar` | `if / else`, ternary operator, `switch` |
| `Ders3_Donguler` | `for`, `while`, `do-while`, `break`, `continue` |
| `Ders4_Metotlar` | Methods, overloading, pass by value, recursion |
| `Ders5_Diziler` | Arrays, for-each, `Arrays` helper class, 2D arrays |
| `Ders6_Stringler` | `String`, `==` vs `equals`, immutability, `StringBuilder` |

### OOP (`src/oop`)

| File | Topic |
|---|---|
| `Ders7_SinifVeNesne` | Classes, objects, constructors, `this` |
| `Ders8_Kapsulleme` | Encapsulation, access modifiers, getters and setters |
| `Ders9_Static` | `static` fields and methods, `static final` |
| `Ders10_Kalitim` | Inheritance, `super`, `@Override` |
| `Ders11_Polimorfizm` | Polymorphism, overloading vs overriding, `instanceof` and casting |

## How to run

1. Clone the repository
2. Open it in IntelliJ IDEA (JDK 21)
3. Open any file and run its `main` method
